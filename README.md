My Notes Web Application

A lightweight, responsive web application built using Flask (Python) that allows users to securely register, log in, and manage their personal notes.

Features

- User Authentication (Secure Sign Up & Login)
- Session-based user tracking
- Flash messaging alerts (for error/success notifications)
- Create, read, and delete personal notes

Tech Stack

- Backend: Python, Flask
- Database: SQLite (SQLAlchemy)
- Frontend: HTML5, CSS3, JavaScript

Local Setup Instructions

- pip install -r requirements.txt
- python main.py
- http://127.0.0.1:5000
